# 第一章参考分工

本批延续现有样本的暖色像素规范，没有另拼一套 UI。以下四个主要模块每组五个真实来源，逐项用途如下。公开网页的实际访问状态见 [reference-checks.json](../reference-checks.json)；这是页面与设计资料核对，不代表完整玩过相关商业游戏。

## A. 搜索、填写、渐进解锁

| 来源 | 借鉴方向 | 不照搬 |
| --- | --- | --- |
| [The Roottrees Are Dead](https://roottrees.com/en/) | 阅读产生新词，查资料，再自行填写跨来源判断 | 家谱、人物、文章、答案与界面 |
| [Her Story](https://www.herstorygame.com/about/) | 用刚发现的词重新检索，而非只有下一步按钮 | 录像内容、案件与索引答案 |
| [The Rise of the Golden Idol](https://store.steampowered.com/app/2716400/) | 判断人物、事件及证据能说明什么 | 场景、人物、原作填词结构 |
| [NNG Progressive Disclosure](https://www.nngroup.com/articles/progressive-disclosure/) | 最初只露出两个入口，随着发现开放程序 | 不以“解锁”取代阅读和判断 |
| [W3C Error Identification](https://www.w3.org/WAI/WCAG22/Understanding/error-identification.html) | 用文字说明哪一项没对上，保留填写 | 不用只变红或含糊失败提示 |

## B. 周刊、专访、商户目录、资料出处

| 来源 | 借鉴方向 | 不照搬 |
| --- | --- | --- |
| [LOC Chronicling America](https://www.loc.gov/collections/chronicling-america/) | 报刊日期、署名、栏目、文章来源 | 不声称真实馆藏含本作 2006/2023 虚构新闻 |
| [报刊研究指南](https://guides.loc.gov/chronicling-america/about-the-collection) | 让期号、标题与文章出处可回查 | 现实新闻内容和人物资料 |
| [报刊检索技巧](https://blogs.loc.gov/headlinesandheroes/2025/01/tips-for-searching-in-chronicling-america/) | 姓名、不同叫法与搜索词的联系 | 现实档案检索结果，不模拟馆藏认证 |
| [美国城市与电话目录指南](https://guides.loc.gov/united-states-city-telephone-directories) | 商户、营业者、地址和目录年份分列 | 真实住址、电话及私人信息 |
| [照片保存指南](https://www.loc.gov/preservation/care/photo.html) | 区分纸质照片、底片、复制品与后来的扫描 | 现实照片及未经证实的保管链 |

## C. 桌面、固定通讯器、普通生活

| 来源 | 借鉴方向 | 不照搬 |
| --- | --- | --- |
| [Hypnospace Outlaw press kit](https://www.hypnospace.net/presskit.html) | 普通人的网页、旧附件、小店幽默与鲜艳局部 | 广告、人物、音乐及页面模板 |
| [98.css](https://jdan.github.io/98.css/) | 窗口标题栏与控件层级保持一致 | 未引入它的 CSS，未整套换皮 |
| [The Roottrees Are Dead](https://roottrees.com/en/) | 安静的资料阅读环境仍能有探索感 | 家谱与原作 UI |
| [Unpacking](https://www.unpackinggame.com/) | 相机包、黄杯等物件先表达生活，不件件藏线索 | 原作插画和摆放谜题 |
| [OneShot WME](https://store.steampowered.com/app/2915460/OneShot_World_Machine_Edition/) | 同一电脑环境承载人物联系和情绪变化 | Niko、系统皮肤及元谜题 |

整体色彩仍参考 [Eastward](https://eastwardgame.com/media/) 的明亮色彩与生活温度，不使用其角色、地图或图块。本章没有新增恐怖触发、弹窗广告或窗口管理系统。

## D. 字体、长文与可访问性

| 来源 | 借鉴方向 | 不照搬 |
| --- | --- | --- |
| [Fusion Pixel](https://github.com/TakWolf/fusion-pixel-font) | 复用现有中文像素字库及 OFL 许可 | 不手绘汉字，不另加未授权字体 |
| [Silkscreen](https://fonts.google.com/specimen/Silkscreen) | 现有英文像素标题 | 不用于密集长文 |
| [Pixelify Sans](https://fonts.google.com/specimen/Pixelify+Sans) | 评估英文像素字可读性 | 本批只研究，未下载或换字体 |
| [NNG Progressive Disclosure](https://www.nngroup.com/articles/progressive-disclosure/) | 限制开场信息量，功能名称保持清楚 | 不提前显示全部人名和软件 |
| [W3C Error Identification](https://www.w3.org/WAI/WCAG22/Understanding/error-identification.html) | 原生表单、字段反馈、键盘焦点 | 不只用颜色识别错误 |

其余辅助参考（表单标签、BookReader、History API 等）也保留在访问记录中。未制作的酒店、位体教、广告和 B-3 新页面应在后续单独研究，本表不代替它们的设计参考。
