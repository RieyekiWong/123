# 本次文字修订的参考分工

沿用作者交接稿的四组参考，仅用于文体、资料呈现和交互设计，不能当成雪梨镇的真实史料。每个模块列 4–5 项，禁止搬用现实报道、人物原话、图片或其他游戏内容。实际访问状态见 [reference-checks.json](reference-checks.json)。

## 地方报道、专访、来信（5）

| 参考 | 本章用途 |
| --- | --- |
| [AP：Telling the Story](https://www.ap.org/about/news-values-and-principles/telling-the-story/) | 区分事实、引语、归属与照片来源；周年报道和专访 |
| [Cal Poly：Guidelines for Newswriting](https://ucm.calpoly.edu/guidelines-newswriting) | 报道开头先交代事件、时间、地点和参加者 |
| [University of Florida：News Writing for Print](https://ask.ifas.ufl.edu/publication/WC191) | 引语与清楚转述的分工；本次工具访问出现循环重定向，保留作者提供的来源，不宣称已读取页面 |
| [George Mason：News Writing Fundamentals](https://writingcenter.gmu.edu/writing-resources/different-genres/news-writing-fundamentals) | 不把记者文章写成带主题升华的小说 |
| [CUNY：Leads](https://pressbooks.cuny.edu/journalismworkbook/chapter/chapter-8-leads/) | 区分活动新闻与人物特写开头 |

## 搜索、填写、错误提示（5）

| 参考 | 本章用途 |
| --- | --- |
| [The Roottrees Are Dead](https://roottrees.com/en/) | 阅读产生关键词，玩家搜索、交叉判断并填写；不复制家谱、文章或谜题 |
| [W3C：Error Identification](https://www.w3.org/WAI/WCAG22/Understanding/error-identification) | 错误定位到人、店、资料，不清空内容 |
| [W3C：User Notification](https://www.w3.org/WAI/tutorials/forms/notifications/) | 提交后反馈明确，正确后自然进入 GG 新消息 |
| [W3C：Forms Tutorial](https://www.w3.org/WAI/tutorials/forms/) | 只问需要填写的三项，不增加引用清单 |
| [W3C：Validating Input](https://www.w3.org/WAI/tutorials/forms/validation/) | 别名、输入保留和可读错误反馈 |
