# W3-02 — publicity-image artwork

`corridor-base.png` is an original generated scene made for this fictional project on 2026-11-04 using the OpenAI image generation tool. It does not depict or advertise an identified real hotel. The dates printed inside the game are fictional archive dates, not the asset creation date.

All three W3-02 versions use this **same unchanged base file**. `hotel-promo.js` renders brass sign layers and exact lettering with SVG. The original reads `316 / STAFF ONLY / 318`; the synchronized display changes only the central sign to `317`. The preview obscures that sign and can include a small authored SVG silhouette in the service recess, plus a dimmed lamp. A CSS paper layer supplies the low-resolution scanned-print texture. The cleaned sample retains the original labels.

The brief silhouette after source verification is a CSS overlay on the same composition. It is optional and is suppressed by the existing scare and reduced-motion settings. No externally sourced face or real person was added.

The source scene remains in `corridor-base.png`; the file digest, sign coordinates and version definitions are recorded in `credits.json`. Runtime version data is in `hotel-promo-data.js`. Existing real hotel photos, authored CCTV scenes and ordinary advertisements were not overwritten.
