# 第三阶段素材来源

两幅虚构人像来自用户提供的 `Stillwater_第三阶段纯黑世界_视觉剧情设计文档_含参考图.docx` 的内嵌 PNG，分别为 image7.png 和 image8.png。文件原样保留，没有重绘、修图或混入其他游戏截图。

- `fragment-face.png`：主动复核断裂影像时出现的短暂损坏人像。
- `lookback.png`：完成终端操作后，主动回看最后一帧时出现的凝视人像。

文件哈希见 [credits.json](credits.json)。这些是本项目提供的概念素材，不是真实人物或事件摄影。其余纯黑空间、门框、地缝、终端和影像片段由本地 480 × 360 画布程序绘制，没有把带固定 UI 的整张参考图当作游戏场景。文档中旧的 2001 年监控参考未作为发布素材；短暂入口 HUD 使用主线日期 `2006-10-17`，随后剥离。
