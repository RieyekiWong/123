# 静水旅馆 V2.3：最后一条夜班记录

玩家先在「夜猫论坛」帮一位网友看看兼职信息，再从工作样本进入酒店网站查阅 2006 年资料，通过预订、房型、留言、维修单和修改记录逐步调查，最终决定这份记录该怎么处理。保留论坛、七家虚构小店广告及原有调查线；V2.3 在证据核对后增加镜像酒店、三机位空间接力和真实连通判定的配线板。

**直接游玩：[打开中文版](https://rieyekiwong.github.io/123/index-zh.html)** · [English](https://rieyekiwong.github.io/123/index.html)

复制中文版链接发给微信好友即可。若微信内置浏览器显示异常，使用右上角菜单在系统浏览器中打开。这里分享的是游戏网页；无需分享 Codex 环境或 GitHub 仓库权限。

## 下载与启动

在 GitHub 点击 **Code → Download ZIP**，完整解压，再用 Chrome 或 Edge 打开 `index-zh.html`。不要从压缩包中直接打开，也不要把新版脚本混进旧下载目录。英文入口是 `index.html`。

静态页面不需要安装运行库、账号或密钥。如需本地服务器，安装 Node.js 20 或更新版本后运行：

```sh
npm ci
npm run dev
```

浏览器打开 `http://localhost:3000/index-zh.html`。

## 新开场与小广告

论坛页脚只保留论坛链接、广告夹和图片鸣谢；招聘页也有独立页脚。酒店导航、工作笔记、员工档案和游戏设置只在酒店与内部文件页面显示。

新玩家从论坛帖子点击「查看招聘页面」，再点「查看工作样本」进入预订查询。已有 V2 存档会继续之前的页面；页脚「回论坛看看」可以重看开头，不会清除进度。直接打开 `#careers`、`#contact` 等页面仍然有效。

广告配图已换为从 Wikimedia Commons 下载的现成实拍照片，未生成新 logo 或图片。酒店也新增了外观、前厅、活动室、餐厅、庭院和早餐照片，采用 2010 年代官网的米白底色、铜色线条和渐变导航。照片本地打包，原文件不作修改，显示使用最多 480px 的压缩副本；处理方式与逐图许可见 [低清素材表](assets/RETRO-IMAGES.md)。作者、来源、授权另见 [新增照片授权表](assets/WEB-PHOTOS.md) 和网站图片鸣谢。

广告只在论坛和酒店公开页面偶尔出现，可关闭、留着、收起或查看详情。页脚「我的广告夹」能找到保存的广告，也有小镇店铺目录。广告不参与解谜、不播放声音、不收集资料。楼层图、维修、夜审及后半段文件不弹广告；读完 Mara 的备注和进入异常阶段后，返回公开页也不再展示广告。收藏不会删除，真结局后恢复。

广告夹保存在 `stillwater-ads:v1`；本次标签页看过和关闭的广告、冷却时间放在 sessionStorage。它们与主线存档分开，重开主线默认保留广告夹，可在广告夹逐项移除。

## 操作与存档

通过普通链接浏览页面，按档案编号检索，用按钮调整日志顺序，再对照原件提交判断。所有必要信息都在网站里，不需要现实调查。已经核对的原件可从页脚 **Case Notes** 重新打开。

新版自动保存在当前浏览器的 `stillwater-case:v2`。刷新、切换语言后，资料、未完成的排序、勾选、镜头方向、通道连接、接线与开关位置、撤销历史及处理结果继续保留。切换设备或浏览器不会同步。浏览器禁止存储时，页脚会说明无法保存，当前标签页仍可继续操作。

页脚 **声音与设置** 可开启声音、单独允许夜班呼吸声、减少动态、跳过监控突脸，或确认后重新开始。声音每次打开页面都默认关闭；惊吓默认跳过。主突脸只在主动恢复最后一帧时触发一次，无尖叫；静音和减少动态不影响解谜。第二阶段监控内有鼠标附近的小范围玻璃波纹，触屏和减少动态模式关闭。

预订和招聘均为模拟交互，不填写真实姓名、邮箱、电话、简历或支付资料，不会发送申请。

## 维护与发布

```sh
npm run build
npm test
npm run test:e2e
```

构建结果在 `dist/`。GitHub Pages 使用 `main` 分支的 `/ (root)`；其他静态托管可上传 `dist/` 的全部内容。所有资源使用相对路径，支持 `/123/` 仓库子路径。

测试分为新版和上一版，分别运行真实页面。单独检查新版可用 `npx playwright test --project=v2`。开发环境使用已安装的 Chromium 或设置 `CHROMIUM_PATH`。
