# 静水旅馆 · 中文版

这是一部藏在旧旅馆官网中的两阶段互动恐怖谜案。中文版包含首页、客房、旅馆往事、住客留言、入住登记、员工档案、地下章节，以及全部提示和离店记录。

## 下载与试玩

1. 在 GitHub 仓库点击 **Code → Download ZIP**。
2. 完整解压，不要在压缩包里直接打开网页。
3. 用 Chrome 或 Edge 打开 **`index-zh.html`**。

无需安装 Node.js、注册账号、填写邮箱或付款。`index.html` 是保留的英文版，两版右上角都有语言入口。

如果浏览器禁止直接打开本地 HTML，可在项目目录安装 Node.js 20 或更新版本后运行：

```bash
npm ci
npm run dev
```

然后使用服务器上的 `index-zh.html` 入口。

## 如何开始

首次游玩会先显示游戏说明，确认后从求职网站开始，收到招聘消息后进入酒店。随后在「预订与入住」中使用昵称登记，领取 307 号房钥匙，再仔细阅读须知、日记、监控、留言与员工文件。重要内容需要主动记入住客笔记。

公开记录共有六条。看似最终的离店并不是终点：第二章会改变网站外观，开放另外六项调查与新的退房选择。旅馆指南中的菜单、广播卡、服务顺序、照片和事件报告都可能有用。所有谜题都能在本站内解决，不需要进行现实调查或联系任何人。

五种离店记录均有中文剧情；找到真实结局之后，记录仍会保留。

## 新增求职开场

首次打开会进入虚构的「职途招聘」网站，采用蓝色导航、宽搜索栏、职位分类、招聘横幅和求职进度卡。你刚结束上一份酒店接待工作，正在找一份能尽快入职、提供住宿的岗位。可以搜索职位、按类别筛选、查看要求并申请；页面中的职位均无法成功申请。全部职位尝试后，右下角会收到静水旅馆的招聘邀请。点击「查看酒店与岗位」，进入原来的酒店网站；按应聘须知到前台登记、领取临时住宿钥匙，然后继续调查。

求职网站是故事的一部分，不需要真实简历，也不会发送求职申请。进度只保存在本机。已有酒店存档会直接继续原来的进度；想体验新开场，在酒店页脚点击「重看求职开场」，不会清除酒店记录。

## 客服聊天与短暂异常

- 「联系主管」和「联系客服」打开同样的客服式聊天窗口，分别保留两段会话。
- 关键词位于输入框上方，点击会填入问题，再点击发送；也可以直接输入。Enter 发送，Shift+Enter 换行，中文输入法选字不会误发。
- 通常第一次在任一会话中发送第三条消息时，窗口会出现故障，迪伦的求救逐条插入。15 秒后恢复正常聊天，临时消息消失。如果第三条恰好触发假主管，则确认收到后再发送消息，即可遇到迪伦的原有求救。
- 关闭窗口、切换页面或刷新不会重新计时。错过消息时仍可在住客留言中寻找附件。旧存档会保留，新会话从头开始记录。
- 关闭突发惊吓或使用系统减少动态效果后，求助文字仍可阅读，故障视觉效果会减弱。

## 两条完整支线

迪伦的求助不再直接展示在酒店首页。首页可「联系主管」或「联系客服」，住客留言中则有一条署名 D. H. 的普通评价，附带留言里藏着求助线索。404 号房之后的前两个选择仍可进入对应支线。

- **未能送达的求助**：在住客评价的附带留言中发现迪伦·哈克的求助，在阅览室、失物处和早餐节目单中找到三份纸条，核对房号与门禁，进入封存客房。剧情会说明迪伦早已自杀身亡；配图为非血腥的事后虚构场景，不展示死亡方式。带走记录后保存结局 01。
- **最后一班**：通过客服窗口与里德主管对话，登记住宿并领取临时工牌，再进入监控室。三轮巡检共九次确认，画面会陆续出现数字标记，突发人影随惊吓设置开启或关闭。依据迪伦提前留下的场景顺序，核对三位数字解除门锁，保存结局 02。
- **原第三条路线**：原有六份公开记录、服务楼梯、地下六个谜题及最终退房保持原来的流程和答案。新支线资料单独保存，不会增加原来的线索计数；临时工牌也不会解锁原员工档案。

两条支线可分别游玩，纸条、对话、巡检与结局均可续存。监控室内仍可查阅网站资料；返回工作台时已完成的巡检不会丢失。总重置会同时清除新支线。

## 解谜操作改进

- 每个地下谜题及最后的退房选择都有三级可选提示：线索位置、解读方法、直接答案。默认全部折叠，不会自动揭晓。
- 供电与事件排序会显示已选数量，可「撤回上一步」，也可全部清空。
- 收音机支持拖动滑块或直接输入频率；查看节目单后返回，两种输入都会保留。
- 中文重新调整了官网介绍、按钮、维修记录和结局的表达，保留原有酒店布局、谜题答案及两章结构。

## 返回与切换

- 文档窗口左上角的「返回」会回到上一份资料，保留已填答案、收音机频率和已选的供电、时间顺序。
- 在监控内切换频道不会反复增加历史页面；返回会直接回到楼层导览。
- 填写入住信息时打开须知，再返回登记，已填内容会保留。
- 已完成的地下站点会先显示记录；想再操作一次，可点击「重新操作这一关」。

## 中文谜题说明

- 菜单的首字母谜题保留英文菜名，并附中文菜名。请按题目要求提取英文首字母，柜锁仍使用五个英文字母。
- 镜面卡片保留倒置的英文原文，周围说明为中文。恢复英文顺序后，可以提交英文指令，也可以填写对应的中文意思。
- 姓名核对支持档案中显示的中文姓名和英文全名。
- 房号、日期、数字代码、电台名称与频率不随语言变化。
- 您填写的昵称、留言和选项值不会被自动翻译；两个版本使用相同的谜题逻辑与存档格式。

## 惊吓与声音

页面含有异常人影和短暂突发画面。可在页脚「网站说明」中关闭突发惊吓，关闭后所有谜题仍可完成。系统的「减少动态效果」设置会抑制动画。没有快速频闪。

惊吓有三种不同的形象：夜班前台、蒙面住客和镜中人，连续查看异常画面时会轮换。酒店场景已换成五张真实酒店照片，摄影师和授权可在页脚「图片来源」查看，也保存在 `assets/CREDITS.md`。现实酒店与故事无关。

环境音默认关闭，仅在您主动开启后播放。收音机提供文字转录，不开声音也能解谜。按 Esc 或窗口右上角的关闭按钮可退出档案。

## 存档

登记、留言、十二条证据、已完成谜题、惊吓偏好及离店记录只保存在浏览器中，不会发送到服务器。清除网站数据会删除进度；无法保存时，仍可在当前标签页游玩。

通过同一网站地址运行时，中英文版共用进度。直接打开本地文件时，不同浏览器可能将两个入口的存储隔离，建议固定使用同一个入口继续游戏。

「网站说明」中的重新开始会清除两个章节的进度，关闭声音，但保留突发惊吓偏好。

## 游戏说明页（3.7）

首次打开会显示独立的游戏说明页，介绍恐怖内容、基本操作、声音设置、存档与重置方式，并提供可展开的图片作者、原图、授权及语音来源。可以直接开关环境音和突发画面；环境音默认关闭，官网音乐使用独立开关。确认后才进入求职开场；已有进度不会删除。

阅读标记与剧情存档分开保存，同一浏览器通常只自动显示一次。求职网站和酒店页脚都有「游戏说明」，可随时重读。存储不可用时仍可确认进入游戏。重置酒店进度与重看求职开场的差别在说明中分别解释，避免误删记录。


## 官网留声机与旧版样式（3.8）

酒店官网改为较窄的旧式版面，加入纸张底纹、照片细框、渐变导航及略带立体感的按钮。招聘网站、客服聊天和原有解谜流程保留。

第一阶段进入酒店官网后等待 10 秒，尝试播放用户提供的三段 YouTube 视频，顺序为白光的《等着你回来》《期待》《今晚且流连》。第一首从零音量渐入，六秒后达到设定音量；后两首渐入两秒，三首结束后不自动循环。播放器可见，可调整音量或关闭；自动播放被浏览器拦截时，需要点一次播放。YouTube 无法访问或视频不允许嵌入时，不影响继续解谜。

主管、客服异常和假主管出现时，会立即销毁播放器并保存停止标记；调查迪伦、接受工作、进入第二章及后续剧情也会停止。恢复聊天或刷新不会重新播放。重置酒店存档后可再次体验；个人音乐开关偏好保留。游戏说明与求职开场不播放音乐，切到后台时暂停。

测试使用模拟的 YouTube 官方接口验证时序、换曲、淡入和停止。当前执行环境无法访问 YouTube，真实视频能否嵌入及实播效果需在能够访问 YouTube 的浏览器中验证。


## 留声机收起与独立播放区（3.8.1）

播放器已缩小。电脑会在右侧单独留出播放栏，手机使用底部播放区；酒店内容在剩余区域滚动，文字、按钮和住客笔记不会被盖住。播放器保持可见时可继续播放。点击「收起」会暂停并变成一个小按钮，展开后继续当前曲目。收起偏好会保留，刷新后不会自动恢复播放。原有异常与后续剧情的永久停止规则不变。


## 页脚播放器位置（3.8.2）

播放器改为固定放在酒店页脚第一栏的「期待与您再次相见。」下方，作为页面内容随页面滚动。已取消悬浮位置和独立侧栏、底部预留区，游戏恢复完整页面宽度。收起和展开续播功能保留，收起按钮也留在同一个页脚位置。


### 3.9.0 · 酒店官网信息层级

首页收拢为酒店名称、大堂照片、简短介绍与查看客房按钮；保留旧旅馆的配色和装饰。主导航为首页、客房、设施与服务、关于旅馆、预订与入住。住客留言及加入我们从页脚进入。

客房页新增 24 / 28 / 38 平方米及入住人数，保留三种房型、原照片与预订选择。前台服务、早餐、阅览室、庭院与失物招领集中在设施与服务页；设备线路、长住客通知及照片底稿在“入住须知与公告”和“关于旅馆 → 查看旅馆旧藏”中。全部原始故事资料、密码、线索 ID、三条支线及存档格式保留。

页脚新增醒目的“监控室”按钮，未入职时进入主管交接；领取工牌后主导航也显示“监控室”，可以直接进入或继续巡检，仍需完成原有入职条件。招聘详情另设“加入我们”页面。
