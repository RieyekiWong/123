# 静水旅馆 V2：最后一条夜班记录

根据本次提供的 V2 执行任务书与设计企划更新。玩家从一份普通的历史档案复核工作开始，进入 2006 年酒店网站，通过预订、房型、留言、维修单和内部修订逐步调查，最终作出两种不同的归档决定。

**直接游玩：[打开中文版](https://rieyekiwong.github.io/123/index-zh.html)** · [English](https://rieyekiwong.github.io/123/index.html)

复制中文版链接发给微信好友即可。若微信内置浏览器显示异常，使用右上角菜单在系统浏览器中打开。这里分享的是游戏网页；无需分享 Codex 环境或 GitHub 仓库权限。

## 下载与启动

在 GitHub 点击 **Code → Download ZIP**，完整解压，再用 Chrome 或 Edge 打开 `index-zh.html`。不要从压缩包中直接打开，也不要把新版脚本混进旧下载目录。英文入口是 `index.html`。

静态页面不需要安装运行库、账号或密钥。如需本地服务器，安装 Node.js 20 或更新版本后运行：

```sh
npm ci
npm run dev
```

浏览器打开 `http://localhost:3000/index-zh.html`。

## 操作与存档

通过普通链接浏览页面，按档案编号检索，用按钮调整日志顺序，再对照原件提交判断。所有必要信息都在网站里，不需要现实调查。已经核对的原件可从页脚 **Case Notes** 重新打开。

新版自动保存在当前浏览器的 `stillwater-case:v2`。刷新、切换语言后，资料、未完成的排序、勾选及处理结果继续保留。切换设备或浏览器不会同步。浏览器禁止存储时，页脚会说明无法保存，当前标签页仍可继续操作。

页脚 **声音与设置** 可开启低音量提示音、减少动态、跳过短暂连接效果，或确认后重新开始。声音每次打开页面都默认关闭；连接效果默认跳过。本版没有鬼脸贴屏、尖叫或自动播放视频。静音不影响任何解谜。

预订和招聘均为模拟交互，不填写真实姓名、邮箱、电话、简历或支付资料，不会发送申请。

## 维护与发布

```sh
npm run build
npm test
npm run test:e2e
```

构建结果在 `dist/`。GitHub Pages 使用 `main` 分支的 `/ (root)`；其他静态托管可上传 `dist/` 的全部内容。所有资源使用相对路径，支持 `/123/` 仓库子路径。

测试分为新版和上一版，分别运行真实页面。单独检查新版可用 `npx playwright test --project=v2`。开发环境使用已安装的 Chromium 或设置 `CHROMIUM_PATH`。

五张实拍酒店照片继续保留原作者、来源及授权，见网站「图片来源」和 [素材授权表](assets/CREDITS.md)。现实酒店与摄影师不参与虚构剧情，档案位置标注为额外示意层。未使用参考品牌的标识或网站截图作为发布素材。
