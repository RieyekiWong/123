# 静水旅馆 · 中文版

这是一部藏在旧旅馆官网中的两阶段互动恐怖谜案。中文版包含首页、客房、旅馆往事、住客留言、入住登记、员工档案、地下章节，以及全部提示和离店记录。

## 下载与试玩

1. 在 GitHub 仓库点击 **Code → Download ZIP**。
2. 完整解压，不要在压缩包里直接打开网页。
3. 用 Chrome 或 Edge 打开 **`index-zh.html`**。

无需安装 Node.js、注册账号、填写邮箱或付款。`index.html` 是保留的英文版，两版右上角都有语言入口。

如果浏览器禁止直接打开本地 HTML，可在项目目录安装 Node.js 20 或更新版本后运行：

```bash
npm ci
npm run dev
```

然后使用服务器上的 `index-zh.html` 入口。

## 如何开始

先在「预订入住」中使用昵称登记，领取 307 号房钥匙，再仔细阅读须知、日记、监控、留言与员工文件。重要内容需要主动记入住客笔记。

公开记录共有六条。看似最终的离店并不是终点：第二章会改变网站外观，开放另外六个站点与新的离店结算。旅馆指南中的菜单、广播卡、服务顺序、照片和事件报告都可能有用。所有谜题都能在本站内解决，不需要进行现实调查或联系任何人。

五种离店记录均有中文剧情；找到真实结局之后，记录仍会保留。

## 返回与切换

- 文档窗口左上角的「返回」会回到上一份资料，保留已填答案、收音机频率和已选的供电、时间顺序。
- 在监控内切换频道不会反复增加历史页面；返回会直接回到楼层导览。
- 填写入住信息时打开须知，再返回登记，已填内容会保留。
- 已完成的地下站点会先显示记录；想再操作一次，可点击「重新操作这一关」。

## 中文谜题说明

- 菜单的首字母谜题保留英文菜名，并附中文菜名。请按题目要求提取英文首字母，柜锁仍使用五个英文字母。
- 镜面卡片保留倒置的英文原文，周围说明为中文。恢复英文顺序后，可以提交英文指令，也可以填写对应的中文意思。
- 姓名核对支持档案中显示的中文姓名和英文全名。
- 房号、日期、数字代码、电台名称与频率不随语言变化。
- 您填写的昵称、留言和选项值不会被自动翻译；两个版本使用相同的谜题逻辑与存档格式。

## 惊吓与声音

页面含有异常人影和短暂突发画面。可在页脚「网站说明」中关闭突发惊吓，关闭后所有谜题仍可完成。系统的「减少动态效果」设置会抑制动画。没有快速频闪。

惊吓有三种不同的形象：夜班门房、蒙面住客和镜中人，连续查看异常画面时会轮换。酒店场景已换成五张真实酒店照片，摄影师和授权可在页脚「图片来源」查看，也保存在 `assets/CREDITS.md`。现实酒店与故事无关。

环境音默认关闭，仅在您主动开启后播放。收音机提供文字转录，不开声音也能解谜。按 Esc 或窗口右上角的关闭按钮可退出档案。

## 存档

登记、留言、十二条证据、已完成站点、惊吓偏好及离店记录只保存在浏览器中，不会发送到服务器。清除网站数据会删除进度；无法保存时，仍可在当前标签页游玩。

通过同一网站地址运行时，中英文版共用进度。直接打开本地文件时，不同浏览器可能将两个入口的存储隔离，建议固定使用同一个入口继续游戏。

「网站说明」中的重新开始会清除两个章节的进度，关闭声音，但保留突发惊吓偏好。

## 开发与验证

```bash
npm run build
npm test
npm run test:e2e
```

浏览器测试需要 Chromium；环境没有可用浏览器时，先运行 `npx playwright install chromium`。构建结果在 `dist/`，同时包含中英文入口与所有本地资源。

完整英文剧透攻略保留在 `README.md` 的折叠区域。所有人物、旅馆、预订、故障提示与所谓的网站异常均为虚构。
