# 05 · 分阶段实施与验收

状态：Stage 0 完成；Stage 1–7 未实施。先把结构走通，再填入正式网站和素材，不一次性替换全部运行文件。

## 1. 每阶段的交付边界

| 阶段 | 实际制作内容 | 通过后才能进入下一阶段的条件 |
|---|---|---|
| Stage 0 | 当前仓库审查、备份、故事和路线决策、参考核查、测试基线 | 原运行源文件未改；文档区分已存在/待制作；主分支和网站未变 |
| Stage 1 | 版本启动器、独立进度、八幕文字预览、P1–P8 状态、固定事件队列、微信返回和旧存档兼容 | 从微信到三种占位结局可走通；刷新/回微信/返回/后退不迷路；旧路线仍可用；占位进度不进正式存档 |
| Stage 2 | 正式 P0–P2；论坛主帖/附件；资料馆首页、旧留言和修复项目；普通广告场景策略 | 玩家能理解 2007 停业与 2023/2026 记录矛盾；P2 完成到资助方；广告关闭不缺线索 |
| Stage 3 | 八页位体教官网；人名检索、原始/修订、三展品；P3 和旧演讲污染字幕 | 网站各页有独立内容与有效导航；Nora 的班次/自愿性可用原件推理；关闭长文后准确进入展览 |
| Stage 4 | P4 三轨/字幕；H1；新账号申请和固定消息；上传材料限制；准备 GG 旧引导假设的最小 Prompt 兼容修订 | 静音也可完整解题；接受/忽略均到 P5；没有新 Worker 角色或 AI 判题；接口/人格/配额不变；申请/错帧不因刷新重复 |
| Stage 5 | 原创双照片与叠片 P5；三机位 P6/H2；六接头 P7/H3；独立证词 | 照片真能对齐；三机位有可见依据；B-3 算法全组合等价；保存后必达证词与 Final Trace；手机可操作 |
| Stage 6 | P8 三个新结局、微信尾声、回看、GAME OVER；设置和完整中英文审校 | 不用三次分类；三结局皆可达；来源不混同；RELEASED 得到渡口线索；关闭特效不影响证据 |
| Stage 7 | 全流程实际操作、兼容与异常恢复；根据试玩发现修正；从当前 main 根目录发布切到白名单构建产物发布，维持 Pages URL | 完成下方矩阵；核实线上实际文件而非只看 dist；明确记录自动测试、开发者试玩和外部玩家反馈各自范围 |

每阶段以新 story2 测试加相关原版回归为门槛。没有改共享模块时不重复跑无关大型截图套件；改了聊天、接线或版本启动器时，必须同时回归对应原版功能。

## 3. 重要实施顺序

1. 保存本轮备份引用，建立新状态单元测试和原版存档夹具。
2. 增加版本启动器及加载顺序测试；证明原版不加载新剧情、新版不执行旧剧情包装器。
3. 实现新存储与恢复；先测损坏数据、重复打开与写入失败，再做页面。
4. 接入原微信组件，注册固定事件，测试普通聊天与消息投递，不请求真实 AI 或改变线上部署。
5. 实现精确返回与三类场景策略：普通、重要阅读、恐怖。广告/通知先听策略，再接正式演出。
6. 搭八幕文字预览，测试每处关闭阅读后都去正确下一处；再进入 Stage 2 内容制作。

### 每关必问三件事

1. 玩家现在知道要完成什么吗？以顶部一个完整目标句、一个主要操作核对。
2. 所需资料现在确实能找到吗？用全新状态按正常入口操作，不能预置后期来源补洞。
3. 玩家需要理解资料吗？用错误来源/错误推论/只连点控件尝试，必须得到有意义反馈而非误过关。

P0/P1 是非阻塞情感开场与低难教学，不假装成复杂推理。P2–P7 要各有不同观察操作，P8 是建立在这些操作上的有代价决定。

## 5. 文案审校约束

沿用用户的七条规则：保留事实和意图，减少机械句式；词语准确；信息清楚；语气随载体；细节具体；删去无用重复；长短句自然变化。

不把这七条理解为“每处都更短”。日记可有完整段落，通知宜短，正式会议纪要写清日期/人/设备，英文按关系和载体重新表达。新增数据只能是与世界观相容的虚构资料，不能编造现实统计或权威研究替位体教背书。

常见需要删改的句子：

| 原本容易绕的说法 | 建议玩家可见说法（中 / 英） |
|---|---|
| 当前实体映射与来源位置存在未归一化冲突 | 这份记录写的是楚人，但原件不是他的入住单。 / This entry names Churen, but its source is not his booking. |
| 完成身份分类以实现闭环 | 系统想用楚人的名字补上这条记录。你同意吗？ / The system wants to fill this record with Churen’s name. Do you allow it? |
| 执行档案一致性恢复 | 保留原件，停止覆盖。 / Keep the originals. Stop overwriting them. |

公共网站不要处处出现“不要信任何人”“你已成为系统一部分”之类无来源恐怖口号。恐怖来自具体资料在说谎、具体的人试图求助。
