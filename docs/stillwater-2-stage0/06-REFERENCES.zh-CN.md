# 06 · 互联网参考与使用边界

核查日期：2026-11-05。已读取两个附件，并独立访问其中的 33 个不重复网址，另补 3 个交互规范来源，共 36 个。全部返回 HTTP 200；Bureau 81、OldWeb、Neuralink、Apple Feedback 另用浏览器读取了 JS 渲染正文。没有下载参考图片、报名、订阅或执行真人实验。

**检查范围是公开页面与功能说明，不是完整试玩这些游戏。** 下文“借鉴”是本项目的具体设计选择，不声称参考作品恰好有同一谜题。各主要模块给出 4–5 个来源；可以重复使用一个参考，但借鉴点必须对应当前模块。

| [W3C Focus Not Obscured][R28] | 手机/键盘和遮挡也属于通过条件 | 不仅桌面截图验收 |

## 21. 保留的弹窗广告与平静时段（5）

| 来源 | 具体借鉴及本作改写 | 不能照搬 |
|---|---|---|
| [Cameron’s World][R13] | 千禧年前后装饰可以各有脾气；保留票券、窗口、手机等 25 种现有广告内容 | 不抓取其整套图文，也不把闪烁搬入恐怖证词 |
| [Hypnospace][R07] | 广告与个人内容同属日常网络世界，轻松段落提供反差 | 不复制其品牌、虚构商品与广告文案 |
| [GOV.UK Notification Banner][R35] | 与内容分离的明确提示和操作；本作广告仍有清楚关闭/收藏 | 不把广告伪装成真实系统安全警报 |
| [W3C Focus Not Obscured][R28] | 可以遮部分页面，但不能遮当前键盘焦点和唯一操作 | 不让“真实弹窗感”造成不能继续游戏 |
| [MDN Page Visibility][R31] | 只在允许、可见、平静的页面消耗广告等待，恐怖/后台暂停 | 不积压后一次性爆发，也不清除收藏 |
