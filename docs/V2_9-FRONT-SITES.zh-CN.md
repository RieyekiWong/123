# 4.9.0 · 前三站内容与视觉整合

2026-11-03 · America/Chicago。以已完成的 4.8.0 声音与广告检查点继续开发，未覆盖它们。原设计稿完整保存在 [原稿](briefs/FRONT-SITES-2026-11-03.zh-CN.md)。

## 内容与路径

论坛原来的 `job / cv / printer / save-page / dinner / excuses` 六个主题原样保留。新增 `used-monitor / old-websites / takeaway-note / job-description / photo-filenames / vending-machine / travel-brochure / late-snack` 八篇帖子，以及 `welcome-rules` 置顶公告，共 15 个主题。八篇中文标题、作者、时间、正文及 44 条逐楼回复直接从原稿录入，自动核对原文；英文为逐条对应的口语翻译，账号名跨帖统一。没有将给定正文缩写成范例。漏光显示器和三折旅行册是本地 CSS 示意图；可乐罐、饼干与月亮头像也是本地装饰。

`#forum` / `#forum?view=topics` 为主题目录，四个板块各有实际筛选列表。列表显示作者、最后回复者、日期、真实回复数及虚构浏览数。每篇正文可返回目录；相关讨论和公告入口都可用。公告关闭回复，论坛没有假发帖、假收藏按钮。微信分享继续直达 `#forum?topic=job`，原帖的公司卡片继续前往 `#careers`。

招聘页加入三段公司介绍、三个工作流程、三条公告和四则 FAQ。四个岗位分别为原有预订档案整理员、纸质档案扫描助理、照片与说明文字校对员、目录录入与检索测试助理。只有原岗位提供工作样本，仍使用 `F.reservation` 与原 `data-case-action="sample"`，仅由既有事件记录 C1。其余三个岗位保留归档日期和完整说明，无法投递。关键词与远程/现场筛选对四条记录同时生效，显示实际数量并支持清除筛选。真结局后只有主线职位撤下，其他历史职位继续展示。

酒店保留原来的纸色、灰绿按钮、照片和客房结构，加入原稿的欢迎文字、两段介绍、三个常用入口与 2006 年历史网页说明。原有相册十张照片保留，其中八条图说按原稿补齐；照片可点击放大，支持 Escape 关闭、键盘进入并返回原来的焦点。新增四条 2006-10-17 之前的普通留言，未改写 E. Vale 的关键留言。

明信片正面沿用旅馆外观照片，点击或键盘可翻到普通入住说明；前台便条与三条住店指南均已实现，指南可展开收起。它们只出现在酒店页面。论坛保留蓝灰 BBS 表格，招聘页使用简洁的企业列表和扫描仪线条插画，酒店使用照片边框与旅行明信片。没有向员工后台、监控或黑色空间添加这些装饰。
