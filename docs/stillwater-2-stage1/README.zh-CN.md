# Stillwater Hotel 2.0 · Stage 1 开发预览

本页记录 Stage 1 的历史范围。后续 P0–P2 已由 [Stage 2](../stillwater-2-stage2/README.zh-CN.md) 替换为实际内容与验证；请以对应阶段记录区分已完成内容和占位。

日期：2026-11-06；前端版本：4.20.0。Stage 0 的审查和完整设计仍保留在[独立规划分支](https://github.com/RieyekiWong/123/tree/plan/stillwater-2-stage0/docs/stillwater-2-stage0)。

## 本阶段已实现

- 单一版本启动器。默认 URL 继续现有 V1.3；`?edition=2.0` 或 `#sw2/...` 才启动新预览。两个剧情引擎不会在同一页面一起运行。
- 八幕文字路线、P1–P8 独立状态、当前目标、资料回看、笔记草稿、三级手动提示与三种预览结局。全部预览结局有 GAME OVER。
- 重要反馈等待玩家读完；关闭面板后推进到下一处。刷新会恢复正在读的来源或证词，不靠等待时间自动完成。
- 复用微信、七位日常 AI 联系人、本地备用、房间记忆、未读和输入节奏。GG 的开场卡、新账号申请及关键消息由独立固定事件提供。
- 接受/忽略新账号都能继续。固定消息按 batch 去重，未成功保存的投递不会冒充已完成。
- 通知打开对应联系人；返回浏览器保留实际 DOM、完整 hash/query、笔记和位置。微信里刷新后仍能返回原文件。
- 全部 25 组普通广告和广告夹保留。只有指定平静浏览场景可弹出；来源阅读、恐怖链、CCTV、B-3 和终章停止投放。微信右下的广告避开输入区，不挤网页布局。
- 预览重开保留日常聊天、AI 同意和广告收藏；不清原版存档。损坏的新存档保留原文并说明无法保存，不静默覆盖。

## 不应误认为已完成的部分

这是**文字与状态骨架，不是 2.0 正式完整游戏**。P1–P7 的“验证这一幕的转场”是显式占位操作：先打开本幕来源，再验证反馈和转场。它不冒充已制作的正式推理题。

位体教八页能导航，但完整公共网站正文、展品、声音分轨、原创双照片叠片、三机位画面、NULL H1–H3 和正式结局演出仍在后续阶段制作。资料中明确标注了图片、录音占位。没有生成新图片、声音或视频。

原版 B-3 六接头操作没有改动；其核心全状态指纹也保持一致。新预览的 B-3 目前展示规则和独立证词的转场，正式旋转界面按 Stage 5 接入。没有把原版接线改成一个简单的通过按钮。

## 打开方式

本机运行 `npm start` 后：

- 中文：`http://localhost:3000/index-zh.html?edition=2.0`
- 英文：`http://localhost:3000/index.html?edition=2.0`
- 版本选择：`http://localhost:3000/index-zh.html?edition=choose`

线上同一路径可在发布 4.20.0 后使用：`https://rieyekiwong.github.io/123/index-zh.html?edition=2.0&v=4.20.0`。默认入口没有自动切换到预览，也不记住一个会强制替换正式游戏的版本偏好。正式版完成后再接入默认选择。

## 状态隔离

| 内容 | 预览 key / 行为 |
|---|---|
| 八幕进度 | `stillwater-story:2.0:prototype:v1` |
| 预览聊天 | `stillwater-chat:2.0:prototype:v1` |
| 浏览器快照 | `stillwater-browser:2.0:prototype:v1` |
| 通知调度 | `stillwater-messenger:2.0:prototype:v1` |
| 广告轮换 | sessionStorage `stillwater-ads-session:2.0:prototype:v1` |
| 收藏广告 | 继续共享 `stillwater-ads:v1`，不清空 |
| 原版 case/chat | 只读导入日常记录与明确偏好，不写原 key |
| 正式 2.0 存档 | 当前预览不写 `stillwater-story:2.0:v1`，占位过关不会污染正式进度 |

与 Stage 0 的正式方案相比，本阶段连聊天 journal 也使用 prototype 后缀，防止将占位剧情带入未来正式版。导入仅保留合法普通房间的 user/social、草稿和位置，旧剧情、假账号、pending API 和旧事件进度不复制；原记录仍完整保留。

## 文件职责

| 文件 | 实际用途 |
|---|---|
| `edition-bootstrap.js`、两个 HTML | 保留原加载顺序，互斥加载版本；并行预载、顺序执行，避免串行网络等待 |
| `sw2-data.js` | 八幕、来源、双语文字、路由和占位反馈 |
| `sw2-progress.js` | 本地验证、可达性、存档恢复、导入、提示和场景许可 |
| `sw2-chat-story.js` | 新旧账号注册、固定开场和 batch；不新增 Worker role |
| `sw2-story.js` | 已保存的固定事件投递及关闭阅读后的转场 |
| `sw2-pages.js`、`sw2-style.css` | 文字页面、八页官网骨架、黑暗终章、手机和键盘布局 |
| `sw2-app.js` | 视图、设置、草稿、版本化组件接入和事件绑定 |
| `chat-view.js` | 可选存储/卡片/路由参数；重开可保留 AI 同意；原调用默认不变 |
| `messenger-bridge.js` | 可选命名空间/解析器/策略，稳定字段和焦点恢复 |
| `ad-system.js`、`case-audio.js` | 可选场景与会话参数；原版默认策略保留 |
| `case-ending.js` | 单独的预览结束展示，只展示，不授予进度 |
| `site-files.mjs`、package 文件 | 白名单与版本，未新增 npm 依赖 |
| 两份 `v2-remake` 测试 | 模型、来源模板、接线指纹及真实页面操作 |

`case-state.js`、原剧情/谜题模型、`case-night-model.js`、W3-02 系统、广告内容、AI 协议/transport/personas/config、Worker 和冻结 classic 源文件未修改。
