# Stillwater Hotel V2.6 · 聊天、广告与未归档画面

基线：`35a178f0a295797da427e97d26a1d3b49ec1732c`；当前发行版本 `4.6.0`。在现有新版上继续开发，不覆盖论坛、广告、原调查或存档。第三阶段以用户提供的 DOCX/PDF 设计文档为实现参考；聊天与广告的最新直接要求优先于旧文档的五分钟节奏。

## 从新玩家角度的连续路线

1. **游玩声明 → 群聊。** 声音默认关、鬼脸默认开，但玩家确认前可以修改。GGbond、张靓颖666、小林鸽子从作业、早餐和熬夜聊到兼职；Rieyeki 的消息由玩家输入，不替玩家发言。
2. **分享卡 → 夜猫论坛原帖。** 卡片直接读取已有帖子的标题、作者、时间与摘要，不制作重复帖子。卡片一出现就能走，不强制等整段聊天。
3. **论坛 → 招聘 → 酒店。** 沿用岗位预览与工作样本入口；保留正常浏览自由和现有网站风格差异。
4. **R-4829 / 318 / 317 → 原始调查。** 预订单、留言、楼层图、维修单、当晚记录、Mara 的原稿、停业通知与最终核对均沿用原件和验证，不能猜最终答案跳过来源。
5. **变色与回访 → 监控 → 317 服务通道。** 保留两秒黑屏、被改写的目录与留言、三机位地标接力、门牌/猫眼/合照/推车/维修柜/门锁和已有动作惊吓。
6. **B-3 配线。** 六个接头仍按真实端口连通，须有效接线、隔离 AUTO-WRITE、切 MANUAL、保存配置，并恢复 03:17 最后一帧。该画面下方才出现无机位编号的黑色片段。
7. **主动打开未归档画面。** 旧 HUD 短暂保留，然后在 2.4 秒内剥离；主线日期是 `2006-10-17 / 03:17`，不沿用概念图中 2001 年。
8. **走廊辨路。** 入口、拐角、门外、尽头四个局部空间；比较光线方向、地缝断点与门框缺口。门的规则固定，走错只回这一段入口；第二次返回有淡淡人形，调查后消失。鼠标/触摸可以直接照亮各门，按钮提供等价操作，不靠不可见的小热点。
9. **拼合影像。** 三块片段真实移动，支持拖动、触摸、方向键及按钮微调；对齐检测要求边缘位置实际正确，附 0/3–3/3 提示和局部重试。中央黑区无法补满；主动复核后得到「没有对应机位」，并首次触发损坏面孔。
10. **单一分类终端。** ROOM、GUEST、EMPLOYEE 逐项暴露与 317 用途、原住客/处理人、TEMP-015 自动排班之间的冲突。三项都试过后才可保留 UNVERIFIED。第三次尝试后终端背后有很淡的人形，不给未知存在起名或编起源。
11. **主动回望 → 返回 B-3。** 可选择再看末帧，首次出现另一张凝视面孔。返回后自动滚动并聚焦「锁定原始备份」，继续原夜班终端的最终决定。
12. **原有三个结局。** 自动结案与拒绝签字保留原来的较早选择；新游戏的真结局需完成未归档章节、回到 B-3 锁定原件后退出。最后一次逃离鬼脸和 GAME OVER 保留，明确故事已结束。

这是一条自然主线，不是强制清空其他导航；调查、回看原件、暂时退出第三阶段都不丢进度。第三阶段不是黑色版酒店后台，没有新增编号输入、文件排序、证据勾选或隐藏答案。

## 文案与角色整理

| 原来的问题 | 现在的处理 |
|---|---|
| 「工作」与「工资」共用回复，林鸽子可能接到薪酬问题 | 两个独立意图，回复均由 GGbond；不知道的工资就说没问清，没有凭空报数 |
| 玩家已经问了岗位，脚本随后重新问「什么兼职」 | 接到岗位问题后从接续的工资话题继续；接到工资问题后转向分享请求 |
| 「哈哈」之后突然接到早餐或无关催促 | 使用短的笑声接话，按角色口气，不推断玩家在笑什么 |
| 未识别输入直接回应「我吃完再看」 | 询问玩家指的是哪件事或哪一段，不假装理解 |
| 玩家已说要查看，群里继续问「怎么还没人点」 | 保存本地阅读意向，跳过相关完整问答组，避免半句对不上 |
| 「你不是刚说你才醒」引用了没有说过的话 | 改为「你不是刚起来吗」，不虚构前一句 |
| 英文「Evidence suggests otherwise」像分析口吻 | 改为口语「Clearly they do」 |
| 黑色章节交互容易变成旁白总结 | 查看时只描述可见锚点；终端引用原件事实；返回时说明记录和交接状态，不替玩家解释未知身份 |

原历史聊天 key 保留，已经保存的消息仍能解码。回复是本地有限话题规则，不连接微信或聊天服务，不声称能理解任意自然语言。长线谜题文案、事实及论坛口吻不在本轮随意重写。

## 存档与兼容

- 新版权威存档仍是 `stillwater-case:v2`、`schema:2`；增加 `night.void` 子状态记录场景、路线位置、残片坐标、分类、完成状态和一次性事件。不存在第三套独立通关存档。
- 未完成的旧存档安全补齐默认字段，保留原证据、草稿、摄像头、接线、开关和撤销历史。刷新、换语言及合法直接链接都能续玩；未解锁直接输入 `#void` 会提供当前可用来源入口。
- 已经锁定或已经取得结局的历史存档不会因为更新撤销结局，新增章节可自愿体验。两个原有较早决定仍可直接作出；新游戏真结局需要新增章节完成。
- 聊天仍为 `stillwater-chat:v1`；新的 pacing 标志只缩短旧记录剩余等待一次，不重放消息。保留草稿、上翻位置、待回复与会话。广告仍用原本的独立 local/sessionStorage。
- 只有确认「重新开始」才清除新版调查与聊天。广告夹、经典版存档与玩家此前明确选择的鬼脸偏好保留；声音重开仍默认关闭。

## 惊吓、声音与素材

新增 B（主动复核）和 D（主动回望）各约 700ms，用两张不同原始 PNG。图片完成解码后才开始计时；进度先保存，图片失败不会堵住谜题。每个事件每存档仅一次；不设周期惊吓、不连续重复素材。走廊人形与终端轮廓是低亮度环境变化。

全部沿用鬼脸、静音、减少动态、失焦/离开取消的既有规则。跳过时黑区和分类信息仍然完整；不靠突脸传递唯一答案。声音只在玩家开启后播放低机器声；深入影像与终端才出现很轻的呼吸，突脸后留出安静间隔，不加入爆音或尖叫。

三阶段环境由程序绘制为 480 × 360、4:3 的冷灰低面数空间；没有复制完整带 HUD 的参考图。两张面孔来自用户提供的原创概念文档内嵌 PNG，字节不改，见 [来源](../assets/void-v26/SOURCES.md)。聊天头像为四张现成授权网络摄影，见 [逐图许可](../assets/chat-avatars/SOURCES.md)。没有使用参考微信截图的真实联系人和私人头像。
