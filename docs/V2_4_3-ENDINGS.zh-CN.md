# V2.4.3 · 独立新版与明确收尾

本轮只更新新版。经典版页面、运行脚本、样式、素材和存档不作剧情或功能修改。

## 版本边界

- 新版酒店页脚移除“上一版与原存档”。
- 删除 `below`、`surveillance`、`employees`、`guide` 的跨版本自动跳转；打开这些旧 hash 时留在新版，提供本作可用的资料入口。
- 语言切换、设置、开场说明、结局与资料回看均留在本作。
- `site-files.mjs` 限定新版页面及运行依赖；默认服务器和 `dist/` 只提供新版代码，不包含经典版入口、桥接器或运行脚本。原始媒体与许可仍保留。
- 默认 Playwright 项目只检查新版，不再同时启动经典版服务器。
- `AGENTS.md` 记录后续只维护新版、冻结经典版源码的工作范围。

## 从设备操作到退出

原谜题答案、状态判定和结局条件不变。末段增加实际操作之间的交接：

1. 保存成功后，若最后一帧还未恢复，滚动并聚焦到监控下的恢复按钮。
2. 若配置已保存，恢复最后一帧后聚焦到锁定原件的按钮。
3. 锁定成功后，更新文字为“原件已锁定”，并带到“保留原件并退出夜班”。
4. 退出按钮仍需玩家主动点击，只有原模型允许后才保存真结局。

不新增密码、进度条或证据。前半段核对页面标题改为“资料核对”，避免误以为已经到了整部作品的结尾。

## 完成画面

- 结局 01、02 各显示“结局已达成”，保留原有留任/拒绝结案结果；可关闭网页或返回终端尝试另一种处理方式。
- 真结局先提交退出，保留原有终局鬼脸。鬼脸消失后出现独立的 **GAME OVER / 真结局** 结束卡，并说明“本次故事到此结束，可以关闭网页”。
- 结束页只突出“回看调查记录”和“重新开始”；不再以“查看岗位”作为结局后的主要操作。
- “重新开始”仍打开设置与确认，不直接清除进度。
- 关闭鬼脸、减少动态、图片失败或取消惊吓时照常显示 GAME OVER。加载超过 6 秒会结束等待，不让完成画面卡住。
- 刷新、切换语言和历史结局回看立即显示已完成状态，不重放终局惊吓。浏览器无法保存时，结束卡如实说明，不声称已保存。

`case-ending.js` 只负责完成画面；`case-events.js` 报告终局表现结束或取消。未改 schema 2、C1–C9、`case-state.js`、`case-night-model.js`、论坛与广告数据。
