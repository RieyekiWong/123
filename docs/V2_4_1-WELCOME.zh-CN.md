# V2.4.1 · 游玩声明、默认鬼脸与终局惊吓

在现有新版上继续开发。按用户要求只处理新版，经典版不扩展。保留 `stillwater-case:v2` / schema 2、C1–C9、接线解法和结局含义。

## 玩家现在怎样进入

首次访问先看到一份独立的双语说明，包含虚构内容声明、鬼脸/扭曲/呼吸与剧情主题注意事项、基础操作、图片来源及许可、存档位置与重置方法。不展示编号或谜底，不需要真实个人资料。

- 音效默认关闭，勾选后点击“我已了解，进入游戏”才尝试启用，符合浏览器的手势要求。
- 鬼脸与 Jump Scare 默认开启；玩家可在进入前取消勾选。跳过仍保留全部故事、机关和结局。
- 顶部“游玩说明”可随时重开；设置修改后保留进度。切换语言保留正在选择的偏好，不自动播放声音。
- 新版重置后再次显示声明。浏览器拒绝存储也能确认并进入，不把存储权限当游戏门槛。
- 减少动态仍优先；说明页会告知其正在生效。

## 默认值迁移

新增 `preferences.scareChoiceMade` 记录用户是否主动选择。原版本自动保存的 skipScares=true 且没有明确选择标记时，采用新的开启默认值；有章节确认或明确选择时保留用户关闭的设置。减少动态和声音的默认值不改变。

此前自动跳过的三类面孔，只恢复其未看过的视觉触发机会：门牌、人影、剧情线索、已看过的最后一帧、机关和结局均不重置。再次操作相关物件或恢复缓存即可遇到未显示过的面孔；真实播放过的事件仍不重复。

## 逃离后的大鬼脸

只有通过原有条件真正完成 C 结局、首次点击“保留原件并退出夜班”才安排终局惊吓。先保存完成记录、正常显示结局，再等约 1.8 秒显示另一张低清人像（scare-porter），全屏约 1.1 秒后回到完成界面。保持 CRT 质感，不连续频闪；仅在已开启声音时有短促低音量音效。

重新打开、刷新、切换语言、从笔记回看结局均不重播。鬼脸关闭或减少动态时，不加载终局人像，完成状态照常保存。离开页面、打开说明/设置、按 Escape 或隐藏标签页会取消尚未出现的画面。画面失败也不会撤销已经完成的结局。

手机上操作按钮可能位于监控图像下方；当监控不在视口内时，已触发的面孔以相同 CRT 图层暂时显示在当前视口，避免代码触发了而玩家没看到。不改变解谜按钮、视角或页面滚动位置。
