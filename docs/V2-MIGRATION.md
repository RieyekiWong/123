## 明确取舍

1. 新版采用文档规定的新主线与双结局；旧主线保留为独立上一版，不将 Mara、Dylan、04:04 等互相冲突的故事合并。
2. 酒店一级导航为 Home、Rooms、Reservations、Contact 四个；Guestbook、History 与公告属于次级导航/业务链接，兼顾文档的网站地图与首屏四导航限制。
3. 317 是服务缓冲位，不是密码；E-014 的权限来自已完成的夜审复核，不设置四位员工 PIN。
4. 选择零次怪物突脸；可选的短暂连接恢复提示由明确的夜审操作触发，默认跳过，绝不盖住证据。声音默认关闭、音量有限，不加载第三方播放器。
5. 参考馆站点抓取返回 403，未绕过限制或复制截图。采用文件指定的时代色彩、结构和密度，复用已有获授权照片。

## 单一事实与单一状态

`case-data.js`：时间轴、订房号、房号、人员、两版本字段、C1–C9（source / usedFor / unlockedAt）唯一真值。
`case-state.js`：纯状态转换、依赖检查、排序/分类/版本/结案验证、schema 恢复。浏览器控制器仅通过此模型更新同一存档。
`case-app.js` / `case-style.css`：现代招聘、2006 酒店、内网报表、公告窗口四种业务界面与普通 hash 链接。
